Project Presentation

Does equity toxic-flow detection survive the move to crypto?

Adverse-selection (“toxic”) flow is a market maker’s core risk. Equity microstructure detects it with tools like VPIN and widens spreads in response. I test whether those tools still work on anonymous, high-frequency crypto perpetual futures.

The venue has no counterparty identity and no queue position — the exact inputs these tools assume. So does the signal transfer, or break?
Framing
A methodological transfer study — a pipeline and rigorous evaluation, not a trading product.
Data
Bybit BTC / ETH / SOL perps across three regimes: calm, breakout, stress correction.
Result
VPIN ≈ random (AUC 0.506); a simple classifier beats it (AP 0.29 vs 0.18) under stress.

Reflection

What I’d fix, and what I’d add

Fix

Rigour & correctness

Causal backtest. Hardened to a named prediction (p_logreg, prior-bar → next-bar fill). The old PnL table is a historical oracle-signal result and was not rerun.
Merge robustness. Book features are aligned positionally; a timestamp-keyed join removes a silent drift risk.
Statistical power. ~7 daily blocks/week — CIs span zero in 5 of 6 cells. Needs months of untouched out-of-sample data.

Add

Toward production

Streaming ingestion. Event-time, queue-based feed with online/incremental features and an incremental top-of-book — replacing the per-trade full re-sort.
Richer data. Direct feed for true queue position, order-to-trade ratio, and participant identity — the resolution ceiling public data can’t cross.
Cross-venue signal. Aggregate spot / perp / options, with real transaction-cost modelling in the spread decision.
Takeaway: a defensible negative result with an honest audit trail — the value is in the correctness discipline, not a profit claim.
